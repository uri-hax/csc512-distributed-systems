## Course Description
In CSC 512, you will have the opportunity to learn the overarching principles of distributed systems. We will study and implement fundamental Computer Science concepts that not only power the operating systems we use every day (ike Linux, Mac OS X, and Windows) but are also essential to solve complex problems and deliver solutions that empower everyday people to use computers. 

This course is a semester-long group project. Our goal is to create a distributed testing environment for CSC412 and, hopefully, for other classes as well. By the end of the semester, we will have a prototype environment and a draft research paper to submit to a future conference.

We will run this class mirroring a working group in industry and/or research settings. The results of our efforts should serve as a positive story when you apply for industry or academic positions.


#### Student Learning Outcomes
* Understand and communicate modern Distributed Systems, OS, & Networking concepts.
* Write a design document explaining your approach to developing software.
* Develop small pieces of software that can be combined to solve complex problems in a distributed environment.
* Work with DevOps and Linux environments.
* Create simulated testing distributed environments.
* Create readable code and documentation understood by others.
* Write programs of moderate complexity in Go (with some C and Bash).
* Learn and apply common Networking and Distributed Systems programming in Go.
* Perform simple operations in a Linux command-line environment.
* Read, present, and translate research papers into actionable tasks.

##### Weekly Task Check-Ins

Every week, each student will create and pursue at least one task towards the group effort. What are some example tasks?
* Finding a research paper or technology and presenting it to the group.
* Proposing and completing a task on developing the system.
* Writing a draft section for the group research paper.
* And whatever else we collectively decide is valuable! :)

We will manage tasks and code in this GitHub using GitHub issues.

##### Class Participation

You will be assessed by your class participation throughout the semester. Focus on being present and engaged during our meetings. Provided timely and engaging comments/responses within the discussions and activities. Challenge each other to share ideas and implement them! This is a group effort for all of us. :)
