Projects for Secure DevOps in Distributed Systems from CSC 512

CSC 512 was organized as a semester-long group project. The class studied distributed systems, DevOps, operating systems, networking, and containers while developing software for a testing environment for security and systems programming heavy courses. Undergraduate and Graduate students completed four related projects. The projects are listed below as separate prototypes.

View the course repository Instructor: Shaun Wallace

Projects

Each project addressed a different part of the course's shared testing-environment goal. The descriptions below summarize what is implemented in the repository.

CDUP: C/Java Code Duplication Detector

Source and documentation

CDUP is a static-analysis tool for finding code clones across C and Java source files. It converts both languages into a common intermediate representation before running clone-detection methods.

Implements
Parsing, a dependency matrix, a data-flow graph, and Type I–IV clone detection.
Languages
C, Java, and Python for the analysis code.
Additional work
An optional tree-walking interpreter and data-flow graph visualization.

Code Comment Sentiment Analysis

Source and documentation

This service analyzes comments in source-code submissions. It extracts line and block comments, creates per-file tags, and returns a submission-level summary through a web API.

Implements
File- and submission-level endpoints, language-specific comment extraction, and summary reports.
Deployment
Docker, a Makefile-based workflow, and separate development and production ports.
Model use
A configurable local Ollama model is used as part of the analysis.

Chaos Testing in Virtual Environments

Source and documentation

This project runs student programs in isolated Docker containers and compares baseline behavior with behavior under CPU, memory, and network constraints. This code will randomize the availability of system resources to inject chaos within running processes.

Implements
Submission detection, containerized compilation and execution, resource monitoring, and report generation.
Languages
Python, C, and C++ container images are included.
Current limits
CPU and memory profiles were tested on macOS Docker Desktop. Network profiles require further testing, and I/O chaos is not functional on macOS.

Security Toolkit for Code and Dependencies

Source and documentation

The Security Toolkit combines several existing security scanners behind one command-line interface. It can scan source code, Git history, dependencies, infrastructure configuration, Docker images, running containers, and process memory.

Tools used
Semgrep, Gitleaks, Trivy, Grype, and Docker.
Outputs
Terminal output, JSON reports, Markdown reports, and failure thresholds based on finding severity.
Automation
The repository includes an example GitHub Actions security scan.

These projects were developed during one semester. The repository documents completed features as well as areas that remain untested or incomplete.

Course structure

The course used a working-group format similar to industry and research settings. Students created weekly tasks in GitHub, presented research and technical work to the group, implemented software, evaluated their systems, and prepared individual reports and presentations.

Technical topics

  • Distributed systems, operating systems, and networking
  • Security across DevOps and Linux environments
  • Containers and DevOps
  • Simulated testing environments
  • Deployment on shared Linux virtual machines

Course activities

  • Weekly student-defined project tasks
  • Design documents and implementation work
  • Reading and presenting research papers
  • Final presentations to CSC 412 students
  • Individual systems-style research reports
